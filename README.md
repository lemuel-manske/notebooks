# notebooks

My personal collection of some Jupyter notebooks that I've created for various purposes, such as data analysis, machine learning and data visualization. These notebooks are intended to serve as examples and references for my work, and may contain code snippets, explanations and visualizations related to different projects and topics. Feel free to explore and use them as needed!

Some are written in portuguese, most in english. It depends on the project and the context in which they were applied to.

## Index

- [Blumenau](./blumenau): here, me and some folks from FURB (my college) tried to analyze the distribution of public services across the city of Blumenau (SC), Brazil. We used data from the city's open data portal and created some visualizations to understand how these services are distributed across different neighborhoods

- [FURB](./furb): in this directory, you can find some notebooks related to my work at FURB, on various disciplines
